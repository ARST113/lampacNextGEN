# Синхронизация Lampac

[Скачать готовое обновление](https://github.com/ARST113/lampacNextGEN/raw/refs/heads/main/updates/lampac-sync-update.zip).

В архиве — изменённые исходники и собранные модули Sync, TimeCode и Storage
для lampacNextGEN на .NET 10. Инструкция на русском находится в `INSTALL.txt`
внутри архива и в [scripts/lampac-sync-INSTALL.txt](../scripts/lampac-sync-INSTALL.txt).

После установки: **Настройки → Синхронизация → Синхронизация Lampac**.
Базовый ID подставляется из входа автоматически. Чтобы выбрать другой общий
код для устройств, используйте **ID синхронизации**. Вернуться можно кнопкой
**Использовать базовый ID**. История, закладки и тайм-коды используют один ID.

Плагин «Продолжить» сохраняет адрес
https://arst113.github.io/log/ContinueWatching.js.

Обновление проверено в настоящем интерфейсе Lampa с частной копией сохранённой
истории. Сервер автоматически не обновлялся; требуется ручная установка.
Личные данные в архив не включены.
