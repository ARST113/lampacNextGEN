# lampac-js/uploads — клиентские плагины синхронизации

## sync-guard-v8.js — «Синхронизация (исправленная)»

Заменил штатный плагин синхронизации CUB:

- без эхо-петли между устройствами (закладки не перезаписывают друг друга);
- без фоновой активности, когда экран закрыт;
- правильный адрес сервера (не `localhost` клиента, а `{localhost}` лампы);
- подгружает `bookmark-silent.js` и `/timecode.js`.

Подключение в `init.conf`:

```json
{
  "url": "/lampac-js/uploads/sync-guard-v8.js?v=8",
  "status": 1,
  "name": "Синхронизация (исправленная)",
  "author": "codex",
  "descr": "Sync без эхо-петли, без фоновой активности, с правильным адресом"
}
```

## bookmark-silent.js

Молчаливая запись закладок: локальное хранилище Lampa + POST `/bookmark/add|added`
(get-семантика сервера Sync). Без всплывающих уведомлений и без дублирующих запросов.

## nav-probe.js — диагностика

Временный зонд: маячки о загрузке/фоне/выгрузке страницы, помогает ловить перезагрузки
клиента. Включать только на время диагностики:

```json
{ "url": "/lampac-js/uploads/nav-probe.js?v=np13", "status": 1, "name": "NavProbe (диагностика)" }
```
