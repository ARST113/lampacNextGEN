# Prewarm (Lampac)

Прозрачный прогрев и кэш ответов онлайн-источников. Клиент (Lampa) не меняется:
модуль слушает открытие карточки фильма/сериала (`/lite/events?life=true`),
в фоне опрашивает все балансеры теми же параметрами, что и клиент, и складывает
ответы в собственный кэш. Следующие запросы этих же URL отдаются из памяти
(`X-Prewarm: hit`), без похода на внешний сайт.

## Что даёт

* Источники, которые отвечают 0.3-3.5 с, после прогрева отдаются за 1-5 мс.
* Первая загрузка карточки не меняется (прогрев идёт параллельно с запросами клиента),
  но повторные заходы и переключения между переводами, которые уже попали в прогрев, — мгновенные.

## Ограничения

* Кэш только в памяти процесса: после рестарта Lampac пустой.
* TTL 8 минут, не более 400 записей / 24 МБ.
* Не кэшируются: `/lite/events`, `/lifeevents`, `pidtor`, ответы с `rch` и `accsdb`.
* Ключ кэша включает `uid`, поэтому чужие/анонимные запросы кэш не получают.

## Включение/выключение

`manifest.json` → `"enable": true|false`, затем рестарт Lampac.
Лог: `logs/prewarm.log`.
