Обновление синхронизации Lampac (.NET 10)

Что изменено
В Настройки → Синхронизация добавлен один раздел «Синхронизация Lampac».
Базовый ID берётся автоматически из входа в Lampac. Можно ввести любой другой
общий код на нужных устройствах. История, закладки и тайм-коды используют
одну выбранную область. Кнопка «Использовать базовый ID» возвращает базовую
историю. Синхронизация CUB отключается; сам вход в CUB сохраняется.

Установка на действующий сервер lampacNextGEN
1. Остановите Lampac. Сохраните копии каталогов Sync, TimeCode, Storage и
   Shared из группы модулей Sync. Поместите резервную копию вне module/ и
   mods/, чтобы сервер не загрузил её как второй набор модулей.
2. Архив содержит изменённые файлы, а не полный сервер. Его Modules/Sync/
   соответствует <каталог Lampac>/module/Sync/ в обычной публикации, либо
   Modules/Sync/ в исходниках. В стандартном Docker путь внутри контейнера:
   /lampac/module/Sync/. Используйте фактический каталог ваших модулей.
3. Скопируйте файлы .cs и .js в соответствующие места, сохраняя остальные
   файлы. Обязательно обновите все три модуля и соседний каталог Shared.
   Не заменяйте существующие manifest.json целиком. Сохраните enable, dynamic,
   tree и свои syntaxPaths; добавьте строку ../Shared/SyncIdentity.cs в массив
   syntaxPaths каждого из трёх manifest.json. Образцы входят в архив.
4. При загрузке модулей из исходников DLL из архива не нужны. Если ваша сборка
   загружает готовые Sync.dll, TimeCode.dll и Storage.dll, замените именно
   существующие сборки в их текущих местах. Shared.dll заменять не требуется.
5. Если есть plugins/override/sync.js, bookmark.js, timecode.js, invc-ws.js или
   sync-account.js, сервер предпочитает их новым файлам модулей. Сохраните
   собственные изменения и совместите эти переопределения с новыми скриптами
   до запуска. plugins/sync-invc.js из действующего модуля сохраняется.
6. Запустите Lampac и полностью перезапустите Lampa на устройствах. Существующие
   адреса /sync.js, /timecode.js и /bookmark.js менять не нужно. sync.js сам
   подключает два остальных скрипта; общий пункт настроек появляется один раз.

Не заменяйте init.conf, базы данных или историю пользователей. В архиве их нет.
Для контейнера сохраните обновлённые файлы в постоянном томе, чтобы пересоздание
контейнера не вернуло старые модули.

Как пользоваться
Откройте Настройки → Синхронизация → Синхронизация Lampac.
Без изменений используется «Базовый ID». Для общей синхронизации выберите
«ID синхронизации» и введите одинаковый код на устройствах. Допускается
1–128 символов. Каждый новый код имеет свою историю; прежняя сохраняется
отдельно и возвращается при выборе её ID. Если ввести существующий базовый ID
или пароль входа, подключится его прежняя история.

Плагин «Продолжить» остаётся по прежнему адресу:
https://arst113.github.io/log/ContinueWatching.js
Его исправление памяти при смене ID опубликовано отдельно по этой же ссылке.

Проверка
В новом разделе должен быть статус «Подключено». Проверьте перенос просмотра,
закладок и позиции между двумя устройствами с одинаковым ID. Возврат к базовому
ID должен вернуть его историю. /sync/account проверяется с действующим входом
в Lampac; это защищённый маршрут.

Проверено: 31 клиентская проверка, 18 проверок серверных контроллеров, 36 проверок
«Продолжить», публикация трёх модулей .NET 10 и настоящий интерфейс Lampa в
Chromium с закрытой копией сохранённой истории. Личная история, пароли и базы
данных в пакет не включены. На действующий сервер пакет автоматически не ставился.
